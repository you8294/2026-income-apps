# 🚀 스마트 유틸리티 (Smart Utility)

서버 유지 비용 없이 **GitHub Pages**를 통해 배포하는 구글 애드센스 수익형 웹사이트 프로젝트입니다.  
높은 단가(CPC)를 자랑하는 '금융/취업' 카테고리의 유틸리티 도구(계산기)와 SEO 최적화 정보성 블로그 글을 결합하여, 안정적인 트래픽과 자동화 수익(Passive Income)을 창출하는 것을 목표로 합니다.

---

## � [제안] UX 개편 및 애드센스 수익 극대화 전략 (Hub & Spoke 모델)

현재 특정 도구(글자수 세기)가 메인 페이지(`index.html`)로 일대일 매칭되어 있는 구조를 개선하여, 사용자가 전체 서비스를 한눈에 파악하고 가장 높은 애드센스 수익을 창출할 수 있는 **'종합 허브(Hub) 메인 페이지'** 중심의 구조로 개편합니다.

### 1. UX (사용자 경험) 향상
- **직관적인 탐색 (대시보드 형태):** 사이트 접속 시 글자수 세기, 연봉 계산기, 퍼센트 계산기 등 모든 핵심 도구와 최신 팁들이 세련된 그리드 카드 형태로 나열되어, 사용자가 원하는 기능을 한눈에 찾을 수 있습니다.
- **브랜드 신뢰도 상승:** 특정 계산기 하나만 단편적으로 보여주는 것보다, 유용한 툴들이 조직적으로 짜여진 '플랫폼' 형태로 보여질 때 사용자는 전문성을 느끼고 '즐겨찾기' 등으로 재방문할 확률이 대폭 높아집니다.

### 2. 구글 애드센스 수익화(Monetization) 가속화 방안
- **체류시간(Dwell Time) 및 페이지뷰(PV) 극대화:** 
  하나의 도구만 쓰고 즉시 이탈(Bounce)하는 비율(이탈률)을 획기적으로 낮춥니다. 허브 페이지의 썸네일과 카탈로그를 보며 "연봉 실수령액도 계산해볼까?", "청년도약계좌 조건도 알아볼까?"라며 사람들의 호기심을 자극해 연속적인 클릭(페이지 이동)을 유도합니다. 페이지뷰가 늘어나는 만큼 광고 노출 횟수(Impression) 또한 비례해서 급증합니다.
- **프리미엄 광고 배치 영역 확보 (높은 단가):** 
  트래픽이 가장 몰리는 새로운 메인 허브 화면 최상단, 그리고 리스트 중간중간에 가장 자연스러운 '인피드 광고'나 '멀티플렉스 광고'를 삽입할 수 있습니다. 억지로 넣은 광고가 아니라 콘텐츠의 일부처럼 보이게 하여 클릭률(CTR)을 방어하고 단가를 높입니다.
- **거미줄 내부 링크에 의한 강력한 SEO (검색 최적화):**
  구글 검색 로봇(Bot)은 중앙의 튼튼한 허브에서 하위 문서들로 방사형으로 뻗어나가는 'Hub & Spoke' 링크 구조를 권위 있는 사이트의 표본으로 인식합니다. 새로운 메인 페이지가 든든하게 앵커(Anchor) 역할을 해주면 하위 도구와 팁 문서들의 검색 상위 노출 순위가 일제히 동반 상승하는 견인 효과를 만듭니다.

### 🎯 향후 구체적 실행 계획 (Action Plan)
1. **메인 분리:** 기존 `index.html`(글자수 세기)의 파일명을 `char-count.html` 등 본래 목적에 맞는 명확한 이름으로 변경합니다.
2. **신규 Hub(메인) 제작:** 새롭게 `index.html`을 생성해, 모든 유틸리티와 인기 팁들을 모아보는 세련된 홈 화면을 디자인합니다.
3. **글로벌 네비게이션 적용:** 기존 모든 HTML 파일 상단에 일관된 헤더 메뉴(GNB)를 적용하여 어느 페이지에서든 '홈'과 '다른 도구'로 즉시 이동할 수 있는 동선을 구축합니다.
4. **파일 구조 및 내부 링크 업데이트:** `README.md`의 구조도를 허브 구조에 맞게 변경하고, HTML 내부의 메뉴 `href` 링크들을 전면 업데이트합니다.

## 📈 애드센스 수익화 핵심 전략 (SEO)
이 사이트는 구글 로봇(Bot)의 심사 통과와 검색 상위 노출을 위해 다음 규칙을 철저히 준수하여 설계되었습니다.

1. **풍부한 텍스트량**: 모든 페이지 하단에 1,500자 이상의 전문적인 정보성 텍스트 포함.
2. **체류시간 증가 (유틸리티)**: 사용자가 직접 숫자를 입력하고 결과를 확인하는 상호작용(Interactive) 요소를 배치하여 페이지 머무는 시간을 극대화.
3. **거미줄 내부 링크**: 블로그 글(tip)을 읽은 사용자가 자연스럽게 관련 계산기(도구)를 사용하러 넘어가도록 하단에 [Call To Action] 버튼 형태의 내부 링크 삽입.

## 🏗 앞으로의 확장 및 개발 가이드 (How to Expand)
웹사이트의 규모를 키우고 트래픽을 늘리기 위해 새로운 페이지를 추가할 때의 가이드입니다.

### 1. 새로운 '유틸리티 도구' 추가하기
1. 기존 `percent.html` 파일을 복사하여 새로운 이름(예: `bmi.html`)으로 만듭니다.
2. `<main>` 태그 안의 JavaScript 로직과 입력창 UI를 새로운 도구(예: 비만도 계산기)에 맞게 수정합니다.
3. **[중요]** 모든 HTML 파일의 `<header>` 안쪽 `<nav>` 영역에 새로운 도구로 가는 링크(`<li><a href="bmi.html">...</a></li>`)를 추가해 주어야 합니다.

### 2. 새로운 '정보성 팁(블로그)' 추가하기
1. 기존의 팁 파일(예: `card-tip.html`)을 복사하여 새로운 파일을 만듭니다.
2. `<article>` 내부의 콘텐츠를 새로운 주제로 변경합니다. (이때, `<h1>` ~ `<h4>` 태그를 적절히 활용하여 목차 구조를 명확히 해야 SEO에 유리합니다.)
3. 글 하단에는 내용과 가장 잘 어울리는 유틸리티 도구(예: 연봉 계산기)로 연결되는 링크 블록을 유지합니다.
4. `tips.html` (허브 페이지)에 새로운 글 카드를 추가하여 사용자가 접근할 수 있도록 연결합니다.

## 🚀 배포 및 애드센스 적용 순서 (Deployment)

1. **GitHub Pages 배포**:
   - 코드를 GitHub Repository에 Push 합니다.
   - `Settings > Pages` 메뉴에서 Branch를 `master`(또는 `main`)로 설정하고 저장합니다.
2. **개인 도메인 연결 (필수)**:
   - 가비아, 호스팅케이알 등에서 구매한 도메인을 GitHub Pages에 연결합니다.
3. **구글 서치콘솔 등록**:
   - 구글 검색에 사이트가 노출되도록 서치콘솔에 소유권을 확인하고 사이트맵을 제출합니다.
4. **구글 애드센스 심사**:
   - 애드센스 홈페이지에서 사이트를 추가하고, 발급받은 심사용 `<script>` 코드를 모든 HTML 파일의 `<head>` 태그 사이에 넣습니다.
5. **애드센스 승인 후 광고 삽입**:
   - 승인이 완료되면 HTML 코드 내에 주석으로 표시된 `<!-- 애드센스 광고 위치 -->` (회색 박스) 부분을 지우고, 애드센스에서 생성한 광고 코드로 교체합니다.
